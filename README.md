# BIJU 🍰

## Sobre o Projeto

BIJU é uma aplicação web de uma confeitaria fictícia desenvolvida para fins acadêmicos na disciplina de Engenharia de Software III.

O principal objetivo deste projeto foi praticar conceitos de versionamento de código utilizando Git e GitHub, com foco na criação de branches, realização de commits e execução de merges entre diferentes versões do sistema.

Este projeto foi desenvolvido como um ambiente de aprendizado e experimentação, portanto não está completo e nem tem a pretensão de representar um produto finalizado. O foco esteve na aplicação das práticas estudadas durante a disciplina e na familiarização com fluxos de trabalho colaborativos utilizando controle de versão.

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Objetivo Acadêmico

- Praticar o uso de Git e GitHub.
- Criar e gerenciar branches.
- Realizar merges entre funcionalidades.
- Compreender fluxos de desenvolvimento colaborativo.
- Aplicar conceitos estudados na disciplina de Engenharia de Software III.

## Observação

Este projeto possui caráter exclusivamente educacional e foi desenvolvido com o objetivo de aprendizado durante a disciplina.
